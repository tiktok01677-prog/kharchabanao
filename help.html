Help & guide

Get comfortable with your new money journal.

1. Add money in or out

Tap Add transaction and choose Income or Expense. Add an amount, category and date. These appear instantly in Overview, Activity, Calendar and Insights.

2. Plan monthly budgets

Open My budgets, select a category and set a monthly limit. Budgets compare limits with that month's expenses. They never block you from recording a transaction.

3. Save toward a goal

Create a goal with a name and target. Use Contribute to update its progress. Goal progress is for planning only and does not deduct money from your transaction balance.

4. Set recurring reminders

Choose a name, amount and a day of the month (1–31). Once due, tap Record now to add that month's entry. No automatic payment, reminder notification or background charge occurs.

5. Review your spending

Calendar shows dates with saved transactions. Insights shows spending categories and a six-month expense trend based on entries on this device.

6. Back up your records

Settings → Download JSON backup. Keep it somewhere safe. Restore backup replaces all current local records after confirmation. CSV export contains transactions only, not goals or settings.

7. Publish on GitHub Pages

Extract the ZIP, upload the contents of the kharchabanao folder to the root of your repository, then enable GitHub Pages: Settings → Pages → Deploy from branch → main → root. After publishing, open your HTTPS URL.

8. Android WebView

This is a static website, not an APK. A separate Java Android wrapper can open the published HTTPS URL. WebView file downloads may need a native save-file bridge; test JSON/CSV export and import before publishing an Android app.

9. Troubleshooting

Website not loading? Confirm the GitHub Pages URL and internet. Missing old records? Data is stored per browser/site origin. Use your JSON backup to restore on the new device or origin.
